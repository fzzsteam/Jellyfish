# 创作流程体验优化计划

本文记录仍在推进中的创作流程体验优化方案。它描述接下来要做什么，归属 `plans`；已经稳定生效的页面职责和状态语义，应同步沉淀到 `architecture`，本文只保留仍在推进的体验优化方向。

## 目标

- 让新用户进入平台后能理解从项目到视频生成的主流程。
- 让已有项目清楚显示下一步动作，减少用户在页面间试探。
- 保持章节镜头队列、镜头详情四步流程与全局任务中心的职责边界。
- 保持 `shot.status`、runtime task status、`video-readiness` 三类状态语义分离。
- 第一阶段尽量不新增后端 API，不新增手写前端 service。
- 吸收公司成员反馈，优先改善按钮与引导不清、工作室过于复杂、一键批量生成路径不够突出的问题。

## 第一阶段范围

第一阶段采用“主流程纠偏 + 下一步推荐”，暂不实现完整新手 Wizard。

当前已落地的主流程基线为：

```text
项目工作台（默认章节）
  -> 分镜列表（章节镜头队列）
  -> 镜头详情
     -> 基础信息
     -> 提取确认
     -> 生成视频
     -> 视频结果
  -> 任务中心追踪轻量运行状态
```

在这个基线上，旧 `/studio` 路由仍保留兼容跳转，但不再作为菜单主入口或推荐主路径。

## 成员反馈映射

公司成员需求汇总中提到的优化点会按阶段处理：

- 初始页面复杂、按钮不够明显、用户不知道下一步点哪里：纳入第一阶段，通过下一步推荐、空状态行动卡和更清晰的主按钮处理。
- 分镜准备需要逐镜头点击“提取并刷新候选”：纳入第一阶段，章节分镜提取任务完成后自动提取资产 / 对白候选，并自动关联已有图片资产。
- 旧“分镜工作室”概念过重、用户不易判断当前在准备还是在生成：纳入第一阶段，通过主流程改写、镜头详情四步分层和兼容跳转弱化处理。
- 希望一键生成每条分镜视频，只修改效果不好的视频：纳入第一阶段，强化章节镜头队列顶部的批量生成入口与结果回看。
- `happyhorse-1.0-r2v` 支持最多 9 张参考图但前端体验不足：列入后续能力轨道；若现有 API/generated types 已支持则在实施中并入，否则按 API 变更流程推进。
- 需要更多风格或图片参考：列入后续能力轨道，结合供应商能力和项目风格配置设计。
- 资产图片生成不应覆盖旧图，应列出所有结果供选择：列入资产管理增强轨道，先判断当前是 UI 展示问题还是持久化契约问题。
- 资产管理批量上传本地图片：纳入资产管理增强轨道，列表页上传会按当前类型快速创建资产。

## 资产图片候选池进展

资产图片生成结果保留已作为资产管理增强的 Phase A 推进：

- 图片生成任务返回的所有图片都会保存为候选图。
- 当前图为空时自动采用第一张候选。
- 当前图已有值时，新生成图片不会覆盖当前图。
- 资产编辑页通过候选池查看生成结果，并可显式设为当前图。

批量本地上传已作为 Phase B 落地：

- 资产管理列表页在“新建”旁提供“批量上传”入口。
- 资产管理列表页的“新建”入口直接创建带唯一草稿名的草稿资产并进入编辑页，不再弹出重复的基础信息表单。
- 编辑页点击“生成”时若发现资产名称与已有资产重复，应提示用户改名或编辑已有资产，不发起生成任务。
- 每张上传图片会创建一个当前 tab 类型的新资产，资产名称取文件名并去掉扩展名。
- 上传图会成为新资产的当前图，并同步进入该资产正面图候选池，来源标记为“本地上传”。
- 资产编辑页不再提供图片槽位上传入口，只保留生成与候选池挑选。

`happyhorse-1.0-r2v` 多参考图仍按后续 Phase 推进。

## 页面职责

### 项目大厅与项目工作台

项目入口负责判断项目或章节下一步动作，并把用户送到正确页面。当前已采用“进入项目默认落到当前章节流水线”的方向，后续仍会持续优化下一步推荐与空状态说明。

计划调整：

- `edit_raw` 进入章节编辑。
- `extract_shots` 进入分镜列表并提取分镜。
- `extract_shots` 提取分镜后自动准备资产与对白，减少逐镜头手动刷新。
- `prepare_shots` 进入分镜列表或下一个待确认镜头详情。
- `shoot` 或已就绪章节进入分镜列表，并将用户引导到可继续生成的镜头详情步骤。

### 分镜列表页

分镜列表页作为章节镜头队列。

计划调整：

- 增加章节流程提示：原文、分镜、准备确认、生成。
- 主行动根据状态变化：
  - 有 pending 镜头时，处理下一个待确认镜头详情。
  - 需要继续生成时，进入目标镜头详情的“生成视频”或“视频结果”步骤。
  - 有运行中任务时，显示轻量任务提示与回跳。
- 顶部工具栏继续承担章节级批量生成、批量下载和批量诊断。
- 明确区分信息确认状态、运行时任务状态和视频生成准备度。
- 不再把章节列表页面写成“进入工作室”的中转层。

### 镜头详情页

镜头详情页已经成为单镜头主工作区，当前计划关注的是把四步路径继续讲清楚，而不是回退到多入口心智。

计划调整：

- 保持 `基础信息 / 提取确认 / 生成视频 / 视频结果` 四步顺序稳定。
- 分镜提取后的候选会先由系统自动准备；“提取确认”主要处理缺图、低置信、多候选或需要人工修正的内容。
- “生成视频”步骤继续聚焦关键帧、参考图、视频参数、诊断与单镜头视频生成。
- “视频结果”步骤继续聚焦结果回看、选片、下载与重试。
- 当前镜头 ready 后，引导处理下一个待确认镜头，或留在当前镜头继续生成。
- 保留旧 `/studio` 兼容跳转，但其落点与文案应持续向镜头详情第三步对齐。

### 任务中心

任务中心继续作为通用任务状态面板。

计划保持：

- 展示任务状态、进度、取消、回跳入口。
- 不展示提示词调试上下文、图文映射细节或业务专属摘要。

## 数据与状态约束

- 前端调用继续使用 OpenAPI generated client。
- 不新增手写 service 封装。
- `shot.status` 只表示信息提取确认状态。
- 运行中状态来自任务系统和 runtime summary。
- 视频生成准备度来自 `video-readiness`。
- 如实施中需要后端 API 变更，必须同步后端、OpenAPI、前端 generated types 与对应文档。

## 实施阶段

1. 统一 next-action helper：集中阶段判断、文案和跳转意图。
2. 调整项目大厅与工作台推荐动作：`prepare_shots` 不再跳到旧工作室心智。
3. 调整初始/空状态引导与主按钮：让新用户明确下一步，不实现完整 Wizard。
4. 调整分镜列表页：稳定章节镜头队列定位，并拆分信息确认状态、视频准备度与运行任务状态。
5. 调整镜头详情页：补齐四步主路径、下一镜头出口与生成结果回看，并将手动提取降级为修复入口。
6. 调整兼容 `/studio` 跳转：保证仍可回跳，但不再作为主文案和主导航入口。
7. 强化章节顶部批量生成、批量下载和批量诊断入口。
8. 校验任务中心边界：保持轻量通用，不加入业务重上下文。
9. 更新已落地的 architecture 文档。

## 验证计划

实施后至少验证：

- 在 `front` 下运行 `pnpm exec tsc --noEmit`。
- `prepare_shots` 会进入准备队列或待确认镜头编辑页。
- 章节分镜提取完成后，会自动生成资产 / 对白候选并尽量完成可用资产关联。
- 分镜编辑页不再要求用户逐镜头点击“提取并刷新候选”作为主流程。
- pending 镜头不会被当作可生成状态。
- ready 镜头进入镜头详情后，仍需由 `video-readiness` 决定是否可生成视频。
- 镜头详情第三步承担单镜头生成，章节列表顶部承担批量生成与下载。
- 初始页、空项目、待准备章节都有清晰主按钮和下一步说明。
- 旧 `/studio` 文案只保留兼容说明，不再作为主路径描述。
- 任务中心只展示通用任务信息。
- 未修改 API 时不运行 `pnpm run openapi:update`；若修改 API，则必须运行。

## 后续阶段

完整新手 Wizard 和生产指挥中心暂不进入第一阶段。主流程稳定后，可以再评估：

- 首次使用的轻量引导或检查清单。
- 跨章节批量准备与批量生成队列。
- 更高层的生产指挥中心。
- 多参考图视频生成能力，包括 `happyhorse-1.0-r2v` 的最多 9 张参考图体验。
- 更丰富的 AI2D、AI3D 等视觉风格和图片参考配置。
